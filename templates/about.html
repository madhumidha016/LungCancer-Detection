Research Methodology & Technical Architecture

Detailed theoretical formulation of CNN detection, Grad-CAM visual attention mapping, and Counterfactual What-If causal perturbation analysis for thoracic oncology.

1. Research Objectives & Problem Statement

Academic Capstone

Lung cancer remains one of the leading causes of cancer-related mortality globally. While deep convolutional neural networks (CNNs) have achieved outstanding performance in detecting pulmonary nodules on Computed Tomography (CT), clinical adoption is often hindered by the "black-box" dilemma. Clinicians must understand not only what the model predicted, but why it made that determination.

This project bridges that gap by introducing Counterfactual What-If Explainability. In addition to producing traditional visual saliency maps via Grad-CAM, the system applies controlled spatial perturbations (masking, blurring, attenuation) to suspicious regions and re-evaluates the modified CT scan through the identical neural network. This allows researchers to verify whether the detected nodule was the true mathematical cause of the malignancy classification.

2. Convolutional Neural Network (CNN) Pipeline

The detection architecture processes standardized $224 \times 224 \times 3$ axial CT image slices. The network applies hierarchical feature extraction:

Feature Extraction Layers

Stacked 2D convolutional layers with batch normalization and LeakyReLU activations extract textural variations, edge contours of thoracic organs, and localized hyperdensities within the lung parenchyma.

Classification Head

Global average pooling aggregates spatial feature maps into dense representations, followed by dropout regularization and a 2-class Softmax layer producing calibrated confidence probabilities for Normal and Cancer.

3. Grad-CAM (Gradient-Weighted Class Activation Mapping)

Grad-CAM visualizes the coarse 2D attention distribution of the final convolutional layer for a given target class $c \in \{\text{Normal}, \text{Cancer}\}$:

Step 1: Neuron Importance Weight Calculation ($\alpha_k^c$)

αkc = (1 / Z) ∑i ∑j (∂yc / ∂Ai,jk)

where $Z$ is the spatial area of the feature map, $y^c$ is the class score before softmax, and $A^k$ is feature map $k$.

Step 2: Linear Combination & Rectified Linear Activation (ReLU)

LGrad-CAMc = ReLU( ∑k αkc Ak )

The ReLU operator ensures that only features having a positive correlation with the target class are retained in the heatmap.

4. Counterfactual What-If Analysis (The Primary Novelty)

Core Novelty

Traditional Explainable AI methods provide observational correlation rather than causation. Counterfactual analysis asks:

"What would the CNN's diagnosis have been if the suspicious pulmonary nodule had not been present or had lower soft-tissue attenuation?"

Our What-If engine implements three transparent, clinical-grade transformations:

A. Tissue Masking

Replaces high-density nodular pixels with healthy surrounding aerated lung parenchyma density (-800 HU baseline equivalent).

B. Gaussian Blurring

Smooths high-frequency spiculation borders, dissolving nodule margins to test network sensitivity to border irregularities.

C. Intensity Attenuation

Linearly reduces radiodensity within the lesion volume, simulating tumor regression or early anti-neoplastic response.

Causal Verification: If the model's malignancy probability drops significantly and flips from Cancer to Normal upon perturbation, the suspicious region is mathematically verified as the causal driver of the original prediction.

5. Optional TNM Cancer Staging

For cases where the primary detector determines a high probability of malignancy ($P(\text{Cancer}) \ge 50\%$), the pipeline initiates an optional staging module categorizing the lesion according to the International Association for the Study of Lung Cancer (IASLC) TNM classification:

  • Stage I: Localized solitary lesion ($\le 3$ cm) without nodal or distant metastasis.
  • Stage II: Localized tumor with ipsilateral peribronchial/hilar lymph node involvement.
  • Stage III: Locally advanced tumor with mediastinal nodal involvement.
  • Stage IV: Advanced tumor with pleural dissemination or distant organ metastasis.

Note: If a trained staging model file is not available in the models/ folder, the system safely bypasses this step without interrupting detection or What-If analysis.

6. Connecting Real Trained Models

The application is built with a plug-and-play architecture. To deploy a real trained Keras/TensorFlow model:

  1. Export your trained CNN weights as lung_cancer_cnn.keras or lung_cancer_cnn.h5.
  2. Place the file into the models/ directory at the project root.
  3. Ensure the model expects input shape (None, 224, 224, 3) and produces binary or 2-class softmax outputs.
  4. Restart the Flask server. The application will automatically detect and load the real model, switching from Demo Mode to REAL MODEL LOADED.
